# Tic Tac Toe Game

A simple and modern Tic Tac Toe web game built using HTML, CSS, and JavaScript.

## Live Game Link
Click here to play:  
👉 [Play Now](https://shivamyadav76.github.io/tic-tac-toe/)

## Features
- Neon dark theme design
- 2 Player Mode (Play with a friend)
- AI Mode (Play against computer)
- Real-time Scoreboard
- Sound effects and winning celebration
- 
##  Built With
- *HTML*- Structure
- *CSS*- Styling & Layout
- *JavaScript* - Game logic & AI

---

##  How to Play on Your PC
1. Download or clone the project.
2. Double-click on `index.html` to open it in your browser.
